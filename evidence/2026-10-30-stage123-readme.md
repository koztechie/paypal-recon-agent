### What makes the keyless path possible (code changes, all gated & tested)
1. `createPaypalToolkit`: missing creds now throw ONLY when `DRY_RUN != true`
   (real mode unchanged); in dry-run it logs placeholder mode.
2. `withDryRun` is now applied **centrally** in `createPaypalToolkit().getTools()`
   (previously only stage-50's script used it — one decision, one place).
3. `createDraftInvoice`: a `dry_run` stub is returned as-is (no `get_invoice`
   read-through, which would need live credentials).
4. `createInvoiceFromContract`: `buyer_email` optional in dry-run
   (placeholder recipient, never sent anywhere).
5. `scripts/stage100-demo.ts`: guarded `get_invoice` (falls back to the payment
   result), accepts `DRY_RUN_RECORDED`, and labels the verdict honestly —
   `PROVEN (simulated: dry-run mode)` vs `PROVEN`.
6. `.env.example`: `DRY_RUN='true'` documented as the keyless default (switch to
   `false` for real sandbox runs).
